# 方法论

## 核心命题

回测收益 = 可成交收益 + **幽灵收益**。

幽灵收益来自市场根本不会给你的成交：封死涨停上的买入、跌停上的卖出、停牌日的调仓、
当日买当日卖、超过全天成交额的委托。A 股这四类约束比多数市场更硬，而绝大多数回测框架
默认按 `close` 或 `vwap` 全额成交，于是幽灵收益被计入净值曲线，且**系统性偏正**——
因为动量/事件类信号恰好倾向于在封板日发出买入信号。

本 Skill 不重写回测引擎，它做一件事：**把幽灵收益量化出来，并定位到具体交易**。

## 四层约束的执行顺序

顺序不可交换，因为它们的语义不同：

```
inventory_ratio   ← 账户能不能卖（T+1 / 持仓）
market_ratio      ← 市场给不给成交（停牌 / 封板 / 报价越界）
participation_ratio ← 市场能吃下多少（成交额上限）

fill_ratio = min(三者)
```

取 `min` 而不是相乘，是刻意的保守选择：三者不是独立事件，相乘会低估成交、
把审计变成"什么都做不成"。`min` 给出的是**每一层各自允许的上界中最紧的那个**，
是可辩护的下界估计。若要更激进的假设，改 `--limit-open-fill` 与 `--participation`，
不要改聚合方式。

## 关键指标

| 指标 | 定义 | 该怎么读 |
|---|---|---|
| `fill_weighted_ratio` | 按金额加权的平均成交比例 | < 0.8 说明策略假设与市场脱节 |
| `limit_up_entry_rate` | 买入落在涨停日的比例 | **最重要的单一指标**。> 5% 就要把信号顺延一日重跑；> 20% 基本可以判定策略在吃不可得的涨停收益 |
| `limit_down_exit_trap_rate` | 卖出落在跌停日的比例 | 止损策略的致命伤：回测按跌停价出清，实盘被闷在里面继续跌 |
| `phantom_alpha_share` | `(账面 PnL − 可成交 PnL) / 账面 PnL` | 净值曲线的虚高幅度。> 0.3 默认判 fail |
| `t1_violation_count` | 违反 T+1 的笔数 | 非零即为引擎缺陷，先修引擎再谈收益 |

`phantom_alpha_share` 用 `forward_return` 加权计算，方向按 side 定号
（买 = +，卖 = −：卖不掉就等于没有躲开后续下跌）。因此**交易流必须带
`forward_return` 列**，否则只能得到成交率，得不到收益归因。

## 顺延重估：审计之后该做什么

审计给的是"哪些收益是假的"，不是"真实收益是多少"。要得到后者，需要按发现的约束
**重跑回测**，标准做法：

1. 封死涨停日的买入 → 顺延到下一个 `buy_capacity > 0` 的交易日，按该日开盘价成交。
2. 封死跌停日的卖出 → 顺延，持仓继续承担后续跌幅。
3. 停牌日 → 不产生交易，复牌日按开盘价重估，并单独检查停牌期间的跳空。
4. 超参与率的委托 → 拆到多日，并叠加冲击成本。
5. 重跑后再算一次审计：`phantom_alpha_share` 应显著下降；若没有，说明顺延逻辑没生效。

顺延本身会引入新的偏差（顺延日的价格已经包含了当日信息），所以顺延后的曲线仍是
上界估计，不是实盘承诺。

## 判定规则

- `pass`：所有检查都跑了且无发现。**不代表策略有效或未来盈利**。
- `warning`：存在 high/medium/low 发现，但无 critical 且衰减未超阈值。
- `fail`：出现 critical 发现（引擎缺陷类），或 `phantom_alpha_share > --fail-decay`。
- `insufficient-evidence`：状态面板覆盖率低于 `--min-coverage`。此时**不得**给出任何
  定量结论——覆盖率不足时"没发现问题"和"没能力发现问题"无法区分。

critical 与 high 必须附带可定位证据（symbol + date + 具体数值）。没有证据行的高严重度
发现，`validate_audit.py` 会直接判合约违规。

## 确定性与可复现

- 交易流按 `(date, side, symbol)` 排序重放，**同日先卖后买**：卖出只能消耗昨日结算库存，
  买入随后进入冻结库存。这条规则是确定的，写在 `assumptions.intraday_order` 里。
- 同一份 bars + trades + 参数 → 逐字节相同的报告（不含时间戳）。
- 保留数据快照、样本窗、参数取值与所有降级项（`note` / `limit_reliable` / `limitations`），
  使另一位研究员可以复现。

## 已知局限

1. **日线上界**：日线只能区分"一字封死"与"盘中开板"，区分不了封单强度、开板时长与排队
   位置。真实成交概率需要分钟线/逐笔数据。日线判定给的是**乐观上界**。
2. **`limit_open_fill` 是常数假设**：真实开板成交量与开板时长、封单量高度相关。默认 0.3
   是保守占位，必须做敏感性分析。
3. **零期初持仓**：期初有持仓的策略需补期初买入行，否则误报裸卖空。
4. **不建模盘中路径**：同一日内的多笔交易按聚合处理，不还原分笔时序。
5. **不覆盖**：融券、大宗、协议转让、盘后固定价格交易、ETF 申赎、可转债与期货的对应规则。
